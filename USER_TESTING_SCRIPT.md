# DueProof User Testing Script

Run this test with 10 to 20 people. Do not explain the app before the first task.

## Setup

- Use a clean install with no data.
- Test on at least one small iPhone and one large iPhone.
- Include light mode, dark mode, large text, and at least one VoiceOver session.

## Tasks

1. Open the app with no explanation.
2. Explain what you think it does.
3. Add a return claim.
4. Add a gift card claim.
5. Add a warranty with $0 value.
6. Attach proof.
7. Set a reminder.
8. Find the claim later.
9. Mark one claim as recovered.
10. Explain whether you would use it again.

## Questions

- What did you think "Money at Risk" meant?
- Did the app feel trustworthy?
- Did the app feel private?
- Was anything confusing?
- Did anything feel non-Apple?
- Did anything feel ugly or unnecessary?
- Would this save you money?
- What would make you open it again?
- Which screen should be in the first App Store screenshot?
- Would you recommend it?

## Success Criteria

- 90% understand the product within 5 seconds.
- 90% can add a claim without help.
- 90% understand that the app is local/private.
- 80% say they would use it for real.
- 70% say the app feels premium/native.
- No one describes it as cluttered, confusing, or generic.

## Notes To Capture

- Time to first successful claim.
- Fields users hesitate on.
- Whether "proof" and "claim" feel clear.
- Whether $0 warranties/documents make sense.
- Whether privacy copy is reassuring or excessive.
- Any clipped text, small tap targets, or confusing VoiceOver announcements.
